## STEP 1: Create a GitHub Account

**What is GitHub?** Think of it like Google Drive, but specifically for website files. It's free, trusted by millions of people, and it will host your website for free.

### How to do it:

**1.1** Open your web browser (Chrome, Firefox, Safari — whatever you use)

**1.2** Go to: **https://github.com**

**1.3** Click the big green button that says **"Sign up"**

**1.4** Fill in the form:
- **Username:** Pick something simple. Like `mitchsmith` or `northlanddigital`. This becomes part of your website address, so pick something you like!
- **Email:** Your regular email address
- **Password:** Something secure (8+ characters, mix of letters and numbers)

**1.5** Click **"Continue"** and follow the steps. GitHub will ask you to verify your email — check your inbox and click the verification link.

**1.6** When asked what plan to choose — pick **"Free"**. The free plan does everything we need!

**✅ Done!** You now have a GitHub account. Write down your username — you'll need it.

## STEP 3: Upload Files to GitHub

Now we're going to put your files into GitHub so they can be turned into a live website.

### First, create a "repository" (that's just a fancy word for a folder on GitHub):

**3.1** Go to **https://github.com** and make sure you're logged in

**3.2** Click the **"+"** button in the top-right corner of the page

**3.3** Click **"New repository"**

**3.4** Fill in the form:
- **Repository name:** Type exactly this: `aura-ai-studio`
- **Description:** `AI content creation app powered by free AI models`
- **Public or Private:** Choose **Public** (required for free hosting)
- **Add a README file:** Leave this **unchecked** (we have our own)

**3.5** Click the green button **"Create repository"**

You'll see an empty page. That's normal — it's your empty folder!

### Now upload the files:

**3.6** You'll see a message that says "uploading an existing file." Click where it says **"uploading an existing file"**

*(If you don't see that, look for a link that says "upload files" or an "Add file" button)*

**3.7** A page will open that says "Drag files here to add them to your repository"

**3.8** Open the `aura-ai-studio-main` folder on your computer. Select ALL the files inside it:
- On **Windows:** Press Ctrl+A to select all, then drag them to the GitHub page
- On **Mac:** Press Cmd+A to select all, then drag them to the GitHub page

**3.9** Wait for all files to upload. You'll see a progress bar.

**3.10** Scroll down to the bottom of the page. You'll see a section called **"Commit changes"**. 
- In the first box (where it says "Add files via upload"), type: `First upload - Aura AI Studio`
- Leave everything else as-is

**3.11** Click the green button **"Commit changes"**

**✅ Done!** Your files are now on GitHub! You should see them listed on your repository page.

## STEP 4: Turn on GitHub Pages

This is the magic step that turns your files into a real live website!

**4.1** On your repository page, click the **"Settings"** tab (look for a gear icon ⚙️ near the top)

**4.2** On the left side menu, scroll down until you see **"Pages"**. Click it.

**4.3** Under **"Source"**, you'll see a dropdown that says "None". Click it and choose **"Deploy from a branch"**

**4.4** Under **"Branch"**, click the dropdown that says "None" and choose **"main"**

**4.5** Leave the folder as **"/ (root)"**

**4.6** Click **"Save"**

**4.7** Wait about 2-3 minutes. GitHub is building your website!

**4.8** Refresh the page. At the top of the Pages settings, you should now see a box that says:

```
✅ Your site is live at https://YOUR-USERNAME.github.io/aura-ai-studio/
```

**4.9** Click that link! Your website is now live on the internet! 🎉

**✅ Done!** Your app is live. The URL will be:
- **Landing page:** `https://YOUR-USERNAME.github.io/aura-ai-studio/landing.html`
- **App:** `https://YOUR-USERNAME.github.io/aura-ai-studio/app.html`

## STEP 5: Get Your Free AI Keys

The app works right away with Claude built in, but to unlock Gemini and Groq (for even better and faster results), you need free "API keys." 

**What's an API key?** It's like a password that tells an AI service "hey, this person is allowed to use our service." Each key is unique to you.

### Get Gemini API Key (Google) — Great for blog posts:

**5.1** Go to: **https://ai.google.dev**

**5.2** Click **"Get API key in Google AI Studio"**

**5.3** Sign in with your Google account (the same one you use for Gmail, YouTube, etc.)

**5.4** Click **"Create API key"**

**5.5** A long code will appear. It starts with `AIza...`. 
**Copy this code and save it somewhere** (like a notes app or a text file on your desktop)

**⚠️ Important:** Don't share this key with anyone. It's like your personal password.

### Get Groq API Key — Super fast responses:

**5.6** Go to: **https://console.groq.com**

**5.7** Click **"Sign Up"** and create a free account (no credit card needed!)

**5.8** After logging in, click **"API Keys"** in the left menu

**5.9** Click **"Create API Key"**, give it a name like "Aura App", click Create

**5.10** A code will appear. It starts with `gsk_...`. 
**Copy this code and save it** alongside your Gemini key.

### Optional: Get OpenRouter Key (for extra models):

**5.11** Go to: **https://openrouter.ai**

**5.12** Click **"Sign Up"**, create account

**5.13** Go to **"Keys"** → **"Create Key"**, copy the code that starts with `sk-or-...`

**✅ Done!** You have your free API keys. Keep them safe!

## STEP 6: Add Your API Keys to the App

Now we tell the app to use your keys.

**6.1** Open your live app: `https://YOUR-USERNAME.github.io/aura-ai-studio/app.html`

**6.2** On the left side, click **"⚙ Settings"**

**6.3** You'll see three boxes for API keys:
- **Google Gemini API Key** → paste your `AIza...` key here
- **Groq API Key** → paste your `gsk_...` key here  
- **OpenRouter Key** → paste your `sk-or-...` key here (if you got one)

**6.4** Click the **"Save API Keys"** button

**6.5** You'll see a green message: "✓ Keys saved for this session"

**⚠️ Note:** The keys are saved in your browser only. If you clear your browser cookies or use a different browser/computer, you'll need to enter them again. This is actually a good thing — it means nobody else can see your keys!

**✅ Done!** The app is now fully powered up.

## STEP 7: Set Up Your Brand Voice

This is what makes Aura magical. Once you set your brand voice, every piece of content will sound like YOU — not like a generic AI robot.

**7.1** In the left menu, click **"◈ Brand Voice"**

**7.2** Fill in the form:

**Brand / Business Name:**
Type your business name. Example: `Northland Digital Co.`

**What do you do? (one clear sentence):**
Describe your business simply. Example: `We build affordable websites for small businesses in Northern Ontario.`

**Who is your target audience?**
Who are your customers? Example: `Local business owners aged 35-65 who want to get found online`

**3 words that describe your voice:**
How do you want to sound? Example: `Trustworthy, Local, Straightforward`

**Things you NEVER say:**
What sounds wrong for your brand? Example: `No corporate jargon, never say 'leverage' or 'paradigm shift', keep it simple`

**7.3** Click **"Save Brand Voice"**

**7.4** You'll see a green message confirming it's saved!

**✅ Done!** Now every piece of content will have your unique voice baked in.

## STEP 8: Generate Your First Content

The moment you've been waiting for! Let's create something.

**8.1** Click **"✦ Content Writer"** in the left menu

**8.2** At the top, choose your format. Let's start with **"📝 Blog Post"**

**8.3** In the **Topic / Prompt** box, type something like:
```
5 reasons small businesses in Northern Ontario need a professional website in 2026
```

**8.4** Under **Platform / Audience**, choose **"General audience"** or **"Local business customers"**

**8.5** Under **Length**, choose **"Medium (300–500 words)"**

**8.6** Under **Tone**, click **"Professional"** (it should already be selected)

**8.7** Under **AI Model**, leave it on **"Auto (Best for task)"** — the app will pick the best model automatically!

**8.8** Click the big purple button: **"✦ Generate Content"**

**8.9** Wait 5–15 seconds. Watch the magic happen! ✨

**8.10** Your content will appear in the box below! It'll show you which AI model was used and how many words were generated.

**8.11** To copy the content, click the **"Copy"** button. Then paste it into Google Docs, WordPress, or wherever you want to use it!

**8.12** Not happy with it? Click **"Regenerate"** to get a completely different version!

**✅ Done!** You just created AI content for free! 🎉

## Troubleshooting

### "The website won't load / shows a 404 error"
- Wait 5 more minutes — GitHub Pages sometimes takes time
- Make sure the repository is set to **Public** (not Private)
- Double-check the URL: `YOUR-USERNAME.github.io/aura-ai-studio/`

### "The Generate button does nothing"
- Check that you typed something in the Topic box
- Try a different AI model (click Claude instead of Auto)
- Open the browser's developer tools (press F12) and look for red error messages

### "API error: Invalid API key"
- Go back to Settings and re-paste your key (make sure there are no spaces before or after it)
- Check that your key hasn't expired (Gemini keys are permanent; Groq keys too)

### "I don't see my changes after editing files"
- Wait 2–3 minutes after committing changes to GitHub
- Try refreshing with Ctrl+Shift+R (hard refresh) to clear your browser cache

### "The AI-generated content is bad quality"
- Add more detail to your Topic/Prompt — the more detail you give, the better the output
- Try setting up your Brand Voice first (it greatly improves results)
- Try a different Tone setting
- Click Regenerate to get a different version

### "I want to start over / delete everything"
- Go to your GitHub repository → Settings → scroll to the bottom → "Delete this repository"
- Then start fresh from Step 3
