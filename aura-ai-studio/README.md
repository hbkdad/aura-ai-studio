## ⚡ Quick Start (2 minutes)

### Option 1: Use it right now (no setup)
1. Go to the live demo link above
2. Add your free API keys in **Settings** (optional — Claude works without keys)
3. Start generating content!

### Option 2: Run it yourself
```bash
# Clone the repo
git clone https://github.com/YOUR-USERNAME/aura-ai-studio.git

# Open in browser — no server needed!
open aura-ai-studio/landing.html
```

That's it. It's pure HTML/CSS/JavaScript. No Node.js, no npm, no build step.

## 🔑 Getting Your Free API Keys

**Google Gemini** (best for long-form content):
1. Go to [ai.google.dev](https://ai.google.dev)
2. Click "Get API key"
3. Sign in with Google → Create key → Copy it

**Groq** (fastest responses):
1. Go to [console.groq.com](https://console.groq.com)
2. Sign up free (no credit card)
3. API Keys → Create Key → Copy it

**OpenRouter** (access to 20+ models):
1. Go to [openrouter.ai](https://openrouter.ai)
2. Sign up → Keys → Create key → Copy it

Add all keys in the app under **Settings → API Keys**.
